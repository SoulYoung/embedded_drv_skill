# DMA 驱动模块开发规范

## 模块职责

DMA 由控制器父对象和通道子对象组成。通道绑定硬件通道号及请求源，负责方向、地址、传输宽度、循环次数和请求开关。

## 对象架构

父对象使用 c_ref_ 管理创建引用、使用 o_ref_ 管理打开引用。通道创建和打开时各取得一次父对象引用；失败时按相反顺序回退。通道对象只保存 is_open_，不能替代父对象引用计数。

## 实现流程

1. 根据目标手册确认通道数、请求路由、地址偏移、传输宽度、循环计数和中断状态位。
2. 用按通道号索引的对象表保证一个硬件通道只属于一个通道对象；对象表的检查和更新须在短临界区内完成。
3. 首次打开父对象时开启时钟、复位并清除控制器状态；最后一个打开引用关闭时才关闭时钟。
4. 通道打开依次完成：取得父对象打开引用、禁用请求并清状态、配置请求路由和默认控制位、开启硬件中断及 NVIC。
5. 任一步失败均回退已启用的中断、路由、时钟和引用。关闭按打开的反序执行，调用者必须先关闭外设侧 DMA 请求。
6. 完成和错误中断按手册清状态；错误中断先停止本通道请求再通知上层。共享错误中断采用独立引用计数，首个通道开启、最后一个通道关闭。
7. 临界区只保护对象表、软件引用计数和共享 IRQ 引用计数，不包裹寄存器整套配置、等待或回调。

## 验证清单

- [ ] 外设到内存、内存到外设及支持的自定义传输正确。
- [ ] 地址、宽度、循环次数、通道号和请求源越界均被拒绝。
- [ ] 打开中途失败后，时钟、IRQ、父对象引用和对象表恢复到调用前状态。
- [ ] 多通道同时使用时，共享错误 IRQ 的引用和 NVIC 状态正确。
- [ ] 完成、错误和停止后通道可以再次使用。
