# PORT 驱动模块开发规范

## 模块职责

PORT 负责引脚复用、GPIO 输入/输出使能和上下拉配置；不负责电平读写和 GPIO 中断事件处理。

## 必要接口

- `TDrvPortCreate/Destroy`、`TDrvPortOpen/Close`；
- `TDrvPortSetMux`、`TDrvPortSetInputEnabled`、`TDrvPortSetOutputEnabled`；
- `TDrvPortSetPullMode`、`TDrvPortSetOpenDrainEnable`。

未明确需求时不增加特殊接口。驱动能力、输入滤波、锁定和补偿单元仅在接口语义能够准确表达芯片能力时增加到特殊接口。

## 实现流程

1. 从 demo 确认端口组、引脚、复用和上下拉枚举，以及生命周期骨架。
2. 从目标芯片手册确认复用、上下拉、输入/输出使能分别属于哪个外设和寄存器字段，以及各端口和引脚的有效范围。
3. 从芯片时钟树和 SDK 确认 Open 所需的时钟、复位和解锁顺序；不得假定存在独立复用控制器或所有端口共用时钟。
4. 每次仅读改写目标引脚的字段；若芯片提供原子寄存器，按手册规定使用。
5. Close 只关闭对象，不复位已配置引脚，也不关闭可能被 GPIO 驱动继续使用的共享时钟。

## 验证清单

- [ ] 非法 group、pin、mux、pull 返回参数错误；
- [ ] 配置一个引脚不影响同端口其余引脚；
- [ ] 复用、上下拉、输入/输出使能字段均按手册实际写回；
- [ ] 配置方向时仅改变目标引脚位；
- [ ] 目标芯片不支持开漏时，接口返回“不支持”错误码。
