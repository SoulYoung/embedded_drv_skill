# PMC 驱动模块开发规范

## 1. 模块职责

PMC 驱动负责选择目标 MCU 支持的电源模式。时钟、唤醒源、外设停止策略及 RAM/寄存器保持策略均由目标 MCU 用户手册定义；本模块不替上层擅自关闭其它外设。

## 2. 必要接口

- `TDrvPmcCreate/Destroy`
- `TDrvPmcOpen/Close`
- `TDrvPmcSelectMode`

用户未明确提出其它能力时，不增加特殊接口。

## 3. 电源模式抽象

PMC 公开枚举固定为以下四种通用模式，枚举值与 `demo/drv_pmc.h` 保持一致：

| 模式 | 语义 | 平台适配要求 |
| --- | --- | --- |
| Run | 正常运行，不进入休眠指令 | 清除此前设置的深度睡眠控制状态。 |
| Sleep | CPU 内核休眠，系统其余时钟与外设行为由芯片定义 | 按手册配置普通睡眠入口和唤醒条件。 |
| Vlps | 低功耗停止 | 目标芯片若将此能力命名为 DeepSleep，应在此模式中映射实现；没有等价能力时返回不支持错误码。 |
| Standby | 待机 | 按手册设置待机电源域、保持策略和唤醒条件。 |

## 4. 实现规则

1. 先确认每种电源模式的进入条件、时钟状态、保持域、退出方式和唤醒源。
2. `Open` 只配置 PMC 使用所需的公共前置条件；`SelectMode` 才按参数执行模式进入序列。
3. `TDrvPmcSelectMode` 使用 `switch` 按模式分派，使每个模式的寄存器配置和入口序列独立可追溯。
4. 枚举值必须与 demo 保持一致。目标不支持的模式返回现有通用错误码，不能以近似模式代替。
5. 进入低功耗前的外设停止、唤醒源配置与中断清理由调用关系明确的模块负责；PMC 只完成自身手册规定的步骤。

## 5. 验证清单

- [ ] 重复 Create/Open/Close 和空指针均返回确定错误码。
- [ ] 未 Open 时不能切换模式。
- [ ] 每个公开模式均按手册验证进入、唤醒和复位后的状态。
- [ ] 不支持的模式不改变当前电源状态。
