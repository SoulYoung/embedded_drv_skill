# IRQ 驱动模块开发规范

## 1. 模块职责

IRQ 驱动统一管理 MCU 的全局中断开关和 NVIC 独立中断使能状态，不实现具体外设 ISR，也不承载外设中断标志清除和业务回调。外设驱动负责清除本外设中断源并调用自己的状态机或回调。

## 2. 必要接口

- `TDrvIrqCreate/Destroy`；
- `TDrvIrqOpen/Close`；
- `TDrvIrqEnableGlobal/DisableGlobal`；
- `TDrvIrqEnable/Disable`。

用户未明确要求时，仅实现必要接口。NVIC 优先级设置、优先级分组、向量表重定位、Pending 状态操作和系统复位属于特殊接口，直接增加到 `drv_irq.h` 的特殊接口小节。

## 3. 开发步骤

1. 以 `demo/drv_irq.h/.c` 确认对象字段、必要接口、文件头和注释格式。
2. 从用户手册确认中断编号范围、优先级位数、全局屏蔽行为和异常中断限制；接口参数范围必须与目标架构的中断编号定义一致。
3. 从官方 SDK demo 或架构支持包核对中断号类型、独立中断控制和全局中断控制接口的使用方式。
4. 全局中断采用嵌套引用计数时，首次 Disable 关闭全局中断，最后一次 Enable 恢复全局中断；全局中断控制只能通过本驱动成对调用，不混用 SDK 或架构支持包的全局开关。引用上限和溢出错误码由对象字段类型确定。
5. 独立中断操作前检查对象状态和中断编号范围；仅操作目标架构的中断控制器，不配置外设中断源和优先级。
6. Create/Destroy 保持项目对象标记与兜底 Close 语义；全局引用未平衡时 Close 返回失败，避免丢失临界区状态。

## 4. 验证清单

- [ ] Create/Open/Close/Destroy 的重复调用和非法顺序返回正确错误码；
- [ ] 全局中断嵌套 Disable/Enable 在最后一次 Enable 时才恢复；
- [ ] 全局中断引用计数不会下溢或溢出；
- [ ] 非法 IRQ 编号不会访问 NVIC；
- [ ] Enable/Disable 仅调用 CMSIS NVIC 接口，不调用厂家 SDK 包装函数；
- [ ] 驱动不注册 ISR、不清外设标志、不执行用户回调。
